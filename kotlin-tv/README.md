# 红果 TV 原生独立版

这是独立的 **Kotlin + Android 原生 View + Media3** 工程，最低 Android 5.0 / API 21。安装一个 APK，联网后可直接浏览和播放，无需部署 Node、Docker 或填写服务器地址。

- 应用名称：红果TV
- 包名：`com.hongguotv.nativeapp`。
- 收藏和历史保存在本机，可通过「本地备份与恢复」在重装后自动恢复。
- APK 不含 JNI 库，可由 Android 在 ARM32、ARM64、x86、x86_64 上运行；视频解码能力依赖设备。
- 源码分支：`main`；推送不会自动发版，正式版由维护者手动触发 `.github/workflows/release.yml`。
- [下载正式签名 APK](https://github.com/jycao2/hongguoTV/releases/latest)
- 手机遥控端：[hongguoTV-remote](https://github.com/jycao2/hongguoTV-remote)（扫码录入并管理电视入口；遥控页面与按键逻辑内置在本 APK）
- 问题反馈与功能建议：请到 [hongguoTV-updates issues](https://github.com/jycao2/hongguoTV-updates/issues) 提交（该仓库同时承载版本更新与下载）

## 0.30.10 修复

- **双构建修完自动更新链路**：旧客户端（≤0.28.0）装前校验更新包「实际 minSdk == 清单声明 minSdk」，因此更新通道 APK 实际 minSdk 必须是 26。本版起 CI 出两个包：更新通道 `-android8.apk`（minSdk 26，存量 Android 8+ 用户自动更新全通）；Release 页另挂 `-android5.apk`（minSdk 21，Android 5-7 用户手动安装）。构建脚本默认 minSdk 26，出 android5 变体用 `-PHONGGUOTV_MIN_SDK=21`。CI 内以 aapt2 校验两包 minSdk 防呆。

## 0.30.9 修复

- **自动更新链路修复**：0.30.8 更新清单用了新命名 `-android5.apk` 与 `minSdk: 21`，而 0.28.0 及更早客户端只认 `-android8.apk` 与 `minSdk≥26`，存量用户检查更新报「更新信息格式不正确」。本版恢复 `-android8.apk` 命名、清单声明 `minSdk: 26`，并放宽客户端解析为两种命名兼容。实测 0.28.0 客户端可发现新版并下载，但装前校验「实际 minSdk 与声明一致」仍拦下安装（报「包名、版本或签名不匹配」）——最终修复见 0.30.10。

## 0.28.0 新增

- **切集不再弹自动重试**：播放就绪后批量预热前后共 15 集取址（一次签名请求问一整窗），手动切集直接命中地址缓存，不再先转圈倒计时；首帧明显变快。探针实测一次批量取 14 集约 250ms，连续 next×3 + prev×1 零条失败日志。
- **快速切集不再误报失败**：上一集/下一集触发的取流取消不再被当成播放失败（成功与失败分支都校验 `RequestScope.isCancelled`），不会暂停画面并弹重试面板。
- **自动重试界面收敛**：重试期间只显示居中转圈与倒计时，确认键可主动打断切到手动面板；只有预算耗尽、不兼容或解码失败才摆出操作按钮。
- **逐集记忆播放位置**：按「剧:集」记住本次会话里每一集看到的坐标，换集后回看上一集能接着上次位置播；看完的集不留记录。
- **搜索与排行榜上键修复**：网格首行按上键先回本页页头按钮（排行榜的看榜/刷新、搜索的输入行），再按一次才回顶栏；向上找卡时滚动方向按目标位置决定，不再固定向下滚。
- **界面缩放改弹窗选档**：「设置 → 外观与界面 → 界面缩放」由循环切换改为弹窗直接选，新增比「特大」更大的「极大」（1.45 倍）；切换系统风格与缩放都会重建 Activity，重建前记录页签与焦点行，回来后仍在原设置项。
- **遥控在线设备数按 IP 去重**：同一手机多标签/多浏览器在局域网是同一 IP，只算一台设备；遥控页补全屏按钮（隐藏浏览器地址栏）。
- **应用图标改为自适应矢量图标**：删除各密度 mipmap 下的 `ic_launcher.png`，改用矢量背景/前景/单色层与 `mipmap-anydpi-v26/ic_launcher.xml`，适配 Android 8+ 自适应图标。

1. 从本仓库 Release 下载最新正式 APK，首次拷贝到电视安装，或通过 `adb install -r APK文件路径` 覆盖安装。之后在设置 → 版本与更新中完成更新。
2. 在电视应用列表打开「红果TV」，进入首页或搜索。
3. 首页续播和最近观看确认即播放；发现新剧时确认进入详情，选择开始观看。设置中可选择 480P / 720P / 1080P 上限、是否自动连播、系统风格（深夜影院 / 暖玉白）以及清理缓存。

播放中：确认键暂停/播放；左右跳转 10 秒，按住右键 3 倍速快进、松开恢复原倍速；向下直接打开选集，向上或菜单键打开播放、上下集、倍速等更多操作。返回键先关闭选集或收起进度条与菜单，再退出播放；从列表直接续播时回原列表，从详情开始播放时回详情。列表恢复原卡片和页码。

手机遥控：列表页顶栏的「手机遥控」、详情页标题行右侧的同一按钮、播放时控制条上的「手机遥控」，任一处点开都会弹出二维码（设置页左栏「常用」里也保留了一个入口）。手机相机或浏览器扫码即进入遥控页，**连上二维码窗口自动收起**，不挡画面。电视在放片时手机默认是遥控面板（剧名与进度、上一集/下一集/±10 秒/暂停、倍速、静音、弹幕、搜索、当前集快捷条，以及整行的「选集」按钮，点开就是完整选集抽屉，线路组和 5 列网格都在里面）；顶部「遥控 / 浏览」两个分段随时能切，切到浏览形态是方向圆盘加返回/选集/菜单，能像实物遥控器一样在电视上走焦点，播放中也切得过去、再切回来控播放。电视没在放片时自动停在浏览形态（外加带封面的最近观看）。电视上弹出的窗口（退出挽留、更新提示、确认框、选择列表）同样能用方向键、确认和返回操作，不必去摸实物遥控器。开一次会话就能控制整个 App，切到片源或本地库不用重开。顶栏按钮会显示当前状态：未开启、开启后的 `ip:端口`、以及「遥控中 · 手机已连接」。实物遥控器和手机可以同时操作，状态在两边 0.5 秒内对齐。

## 构建

需要 JDK 17、Android SDK Platform 36 / Build Tools 36.0.0。Gradle 8.14.3 包装器已包含；不需要 npm、Node 或 React Native。设置 `ANDROID_HOME`，或在本目录的 `local.properties` 写入 `sdk.dir=SDK绝对路径`。

```sh
# 仓库根目录：开发包直接可安装，无需发布私钥
./kotlin-tv/gradlew -p kotlin-tv :core:test :app:lintDebug :app:assembleDebug
adb install -r kotlin-tv/app/build/outputs/apk/debug/app-debug.apk
```

正式 APK 使用独立发布密钥，**私钥和口令不在 GitHub 中**。重建发布包时，配置以下环境变量，或创建被 Git 忽略的 `kotlin-tv/keystore.properties`：

```properties
storeFile=/absolute/path/to/your-release.jks
storePassword=your-password
keyAlias=your-alias
keyPassword=your-password
```

对应环境变量：`HONGGUOTV_KEYSTORE`、`HONGGUOTV_STORE_PASSWORD`、`HONGGUOTV_KEY_ALIAS`、`HONGGUOTV_KEY_PASSWORD`。使用自己的签名重建时，不能直接覆盖安装官方发布密钥签名的 APK；卸载会清除本机记录。更新已安装的正式版应继续使用同一发布密钥。

```sh
./scripts/build-kotlin.sh
# 输出：outputs/hongguotv-kotlin-0.31.1-android8.apk（更新通道，minSdk 26）
# Android 5-7 变体：./gradlew -PHONGGUOTV_MIN_SDK=21 :app:assembleRelease
# 输出：outputs/hongguotv-kotlin-0.31.1-android5.apk（minSdk 21）
```

## 工程结构

- `core/`：纯 Kotlin 内容列表、搜索、详情、请求签名、播放地址解析、MP4 索引和分段处理；还有局域网遥控服务（监听、SSE 下行、命令白名单解析）与遥控页面 `core/src/main/resources/remote.html`；可在 JVM 测试。
- `app/`：原生电视界面、遥控器焦点、本地收藏/进度、Media3 播放器及自定义 DataSource。
- `core/src/test/`：固定签名对照、NIST AES-CTR 向量、跨样本/非对齐分段、AVC 索引恢复及畸形输入校验。
- `tools/signing-oracle.cjs`：仅开发期生成兼容性测试样本；运行、构建 APK 不需要它。

播放器直接通过 HTTPS 分段拉取数据，经本机 Kotlin 处理后交给 Media3。没有 JS 引擎或常驻内容服务。局域网 HTTP 只在与手机交互期间临时监听，分两种：打开「手机输入」「手机备份与恢复」窗口时按单次任务监听，最长 5 分钟，窗口关闭或应用进入后台后停止；打开「手机遥控」后按长连接监听，页面维持一条 SSE 下行通道（15 秒心跳），无客户端连接空闲 30 分钟自动回收，有连接期间保持监听；应用退到后台时播放暂停、手机端显示「电视已暂停」，回到前台自动接上并补上期间最后一条意图。遥控页面与命令接口都校验路径 token 与来源主机；token 与端口首次生成后写入本机并长期复用（应用启动即静默挂上服务，手机存住的旧地址任何时候打开都能直连，电视端不用再开二维码窗；用户选择「扫码一次、永久直连」即接受密钥长期留存在本机，门禁靠长随机密钥不可枚举、监听只绑内网地址）。命令按白名单解析，越界值直接拒绝。备份下载每次二维码一次，上传成功后关闭会话并等待电视确认。页面不处理平台账号凭据或媒体。媒体只在内存中处理，不下载整部剧到存储。元数据响应、封面大小、索引数量和播放缓冲均有上限。

```sh
# 可选联网检查：真实网站和内容接口，网络变化可能导致失败
./kotlin-tv/gradlew -p kotlin-tv :core:run
# 漫剧分类、搜索两页、详情与真实视频分段检查
./kotlin-tv/gradlew -p kotlin-tv :core:run --args=--comic
# 漫剧排行榜首两页及末页：来源名次、热度、分页和重复检查
./kotlin-tv/gradlew -p kotlin-tv :core:run --args=--ranking
# 重新生成签名对照样本才需要 Node
node kotlin-tv/tools/signing-oracle.cjs
```

## 隐私与匿名统计

0.18.0 起，应用每次启动向自建的腾讯云函数（`*.tencentscf.com`，仅 HTTPS）发送**一次**匿名 GET，用于估算装机量和活跃量，因为 GitHub Release 下载次数会被 CDN 缓存放大，无法反映真实设备数。

- 上报内容只有三项：首次启动随机生成的匿名安装 ID（32 位随机 UUID，仅存于本机 `install_stats` 偏好中）、应用版本名、versionCode。
- **不收集** IP、设备型号、系统版本、位置、观看/收藏内容或任何账号信息；云函数不解析请求来源 IP，只把上述三项写入一行日志。
- 请求超时仅 3-5 秒，失败静默丢弃，不重试、不缓存、不阻塞应用启动；无独立开关，因为不含个人信息且单次请求对使用无影响。
- 日志保留 7 天，统计仅做随机 ID 去重计数（累计安装 / DAU / WAU / MAU / 版本分布）。云函数与查询方式见 `../deploy/scf-stats/`。

除此之外，APK 不包含第三方统计/广告/崩溃上报 SDK。

## 验证边界

当前版本通过 `core` 模块 JVM 单元测试与 Release lint；已在 Android TV 模拟器和 Android 实体电视上验证首页、搜索、详情、连续播放、主题切换和应用内更新。各版本交付证据见对应 `RELEASE_*.md` 记录。最低 API 21 配置和静态检查不等同于所有实体电视验收；遇到设备解码失败可尝试 720P，仍失败需对应电视的日志。

内容来自第三方接口；接口、签名、内容可用性或地区网络变化可能需要更新 APK。此版本不是内容平台官方客户端。
