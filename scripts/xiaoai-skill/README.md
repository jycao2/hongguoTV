# 小爱语音搜任意剧名（小米云函数）

米家那条路只能喊固定名字：米家给第三方设备下发的指令只有「开 / 关」，**协议里没有地方
塞一段文本**，所以无论怎么配，都只能预先在巴法云建主题、把剧名写成昵称。

这份代码走的是另一条路——小米小爱开放平台的**自定义技能**。技能会把用户说的原话（`query`）
发给我们的服务端，于是任意剧名都能拿到。服务端跑在小米自己的「函数计算」里，不用服务器、
不用域名、不用内网穿透。

```
小爱音箱 ──语音──▶ 小爱技能（小米云函数，本目录 main.py）
                        │  把剧名 POST 到巴法云主题的 msg
                        ▼
                  巴法云 hgplay1001
                        │  MQTT（电视常连）
                        ▼
                   红果TV：搜索并起播
```

电视端要 0.28.18 以上（载荷能带剧名的那版）。

---

## 一、注册开发者

1. 打开 <https://developers.xiaoai.mi.com/>，用**音箱登录的那个小米账号**登录
2. 完成实名认证（个人即可，不需要企业资质）

## 二、创建技能

控制台 → 创建技能 → **自定义技能**。

- **调用名称**：全网唯一，说「小爱同学，打开 XXX」就是它。`红果电视` 可能被占或涉及品牌，
  建议先用 `看剧助手` 试。
- **技能类型**：选 **函数计算**（不要选 HTTPS，那个要自己准备域名）

## 三、放代码

技能里 → 函数计算 → 新建工作空间（随便起名）→ 新建函数：

- 运行环境：**Python 3**
- 函数代码：把本目录 `main.py` 全文粘进去，改开头两行：

```python
UID = "47e5b8e577118ff8793fd1f7c5692a09"   # 巴法云私钥
TOPIC = "hgplay1001"                        # 你在巴法云建的那个主题
```

保存后 → 新建触发器 → 类型选 **skillTrigger** → 生成后复制那串 **key**。

## 四、把 key 填回技能

回到技能配置的「服务对接 / 函数计算」处，粘贴刚才的 key。保存。

## 五、配意图

关键点：**真正干活的是 `query` 原文**，意图配得粗一点也能用，但必须让平台肯把话转过来。

- **欢迎意图**：说「打开看剧助手」时触发，回一句「要什么片子？」
- **一个自定义意图**（比如 `Play`）：加几条语料
  - `播放{剧名}`
  - `我想看{剧名}`
  - `看{剧名}`
  - `{剧名}`（单独一句，这条最重要——用户进入技能后通常只说片名）
- **无法理解意图**：也交给服务端（它会自己兜底回「再说一次片名」）

槽位 `{剧名}` 如果要求绑定词表，就把词表留空或选「自定义/泛化」——**不绑词表也能拿到原文**，
因为代码读的是 `query`，不是槽位值。

## 六、测

1. 控制台的 **Web 测试**：输入「打开看剧助手」，再输入 `黄石第五季`
2. 真机：对音箱说「进入开发者模式」，再说技能调用名，然后说片名。
   （开发者模式 1 小时不说话会自动退出）
3. 电视上应该直接开始搜这部片

自测没问题后，**提交审核上线**。不上线的话，每次用之前都得先说「进入开发者模式」，
而且只有你自己的小米账号能用。

## 七、怎么用

上线后：

> 「小爱同学，打开看剧助手」
> 「黄石第五季」

两句。第二句说什么都行，搜不到会提示换说法，不会乱播（电视端有标题匹配兜底）。

## 排错

| 现象 | 原因 |
|---|---|
| 小爱回「没有这个技能」 | 技能还在测试态，先说「进入开发者模式」 |
| 小爱说「没听清 / 你要看什么」 | `query` 是空的，去看技能日志里收到的 JSON，把 `heard()` 里缺的字段补上 |
| 小爱说「电视没连上」 | 云函数出网失败，或巴法云私钥/主题填错。话术里会带巴法云的返回 |
| 电视没反应 | 电视端低于 0.28.18；或巴法云主题不是 `hg` 开头（电视只订阅这个前缀） |
| 片名被削掉开头 | `clean()` 里的 `LEAD` 误剥，把那个词从元组里删掉即可 |

本地只想验证清洗逻辑：

```bash
python main.py "播放黄石第五季" "我想看放羊的星星" "看 狂飙"
```

`LEAD` 里刻意不含 `打开`、`请`、`给我`、单字 `看/放`：这些开头的真片名不少
（打开生活的正确方式、请回答1988、给我一支烟、放羊的星星）。
