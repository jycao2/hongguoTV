# 语音指令速查表

> 由代码导出，**别手改**：说法来自 `core/VoiceIntent.kt` 的 `RULES`，动作键来自 `core/LanRemote.kt` 的
> `REMOTE_ACTIONS`。改完词表跑 `python scripts/gen-voice-cheatsheet.py` 重新生成，省得两边各说一套。

规模：**59 组说法 / 50 个动作键 / 8 个模块**；另有 5 条走专用解析（剧名+集数、序数定位、快进快退、倍速、返回），因为它们的参数不是固定值，放进词表反而说不清。

## 三种入口，同一套命令

| 入口 | 怎么用 |
|---|---|
| 手机遥控页 | 电视上说「遥控地址」，手机浏览器打开，输入框打字或键盘语音 |
| 局域网 | `POST {遥控地址}/cmd`，body `{"cmd":"say","text":"检查更新"}` |
| 小爱同学 | 巴法云主题把原话转发到电视，同样走 `VoiceIntent`（自建技能见 `xiaoai-voice.md`） |

回执是电视上的短提示（Toast），不打断画面。所有说法都可以加「帮我 / 我要 / 我想 / 小爱同学」开头，
句尾「一下 / 吧 / 呢」可省。

## 一、搜片与选集

| 说法 | 执行 | 说明 |
|---|---|---|
| 我要看文盲修仙 / 搜一下末世日常 / 播放斗罗大陆 | `watch(query)` | **只把结果摆出来**，不自动播 |
| 我要看文盲修仙的第七集 / 第 12 话 / 第 3 期 | `watch(query, episode=7)` | 说清集号才直接落到那一集 |
| 第七集 / 第5集（已经在看某剧） | `list.play episodes:7` | 当前这部剧的第 7 集 |
| 历史记录第二个 / 收藏第 3 个 / 选集第五个 | `list.play <列表>:N` | 定位列表第 N 条并播放 |
| 第二个（单独说，不带列表） | `list.play current:N` | 只在整句几乎只有序号时才认，防片名误判 |

列表键：`history` 最近观看 / `favorite` 收藏 / `episodes` 选集 / `catalog` 当前列表 / `current` 当前页。
搜不到就停在结果页提示换说法；搜到的剧没有正片（空壳、预告）同样只列结果、不进播放器；
当前内容库搜不到会自动换库（漫剧 ⇄ 短剧）再搜一次。

## 二、进度、倍速与定时

| 说法 | 执行 | 说明 |
|---|---|---|
| 快进 30 秒 / 前进一分钟 / 往后 15 秒 | `step(+30000)` | 只说「快进」默认 15 秒，上限 10 分钟 |
| 快退一分钟 / 后退 15 秒 / 倒回去 2 分钟 | `step(-60000)` | 同上 |
| 1.5 倍速 / 两倍 / 半倍 | `speed(1.5)` | 落最近档位 |
| 半小时后关掉 / 定时 30 分钟 / 看完这集就关 | `sleep.set`（`min:30` / `ep:1`） | 只开界面已有的档位 |

片名保护：「黄石**第五季**」不会被当成第五个；「八倍镜」「三倍人生」不会被当成倍速；
不带「倍速」的句子要求「倍」正好落在句尾。

## 附录 C：容错边界（认不出时为什么不动）

- 解析顺序：剧名+集数 → 列表序数 → 快进快退 → 倍速 → 定时 → 动作词表 → 模块 → 返回 → 模糊 → 当剧名搜索。
- 模糊兜底要求**别名的每个字都出现**，两个动作得分并列就放弃。曾经放过 0.75 的宽松档，
  「关闭弹窗」被吃成「关闭弹幕」——四个字错一个，语义可能整个拧了，所以宁可不猜。
- 认不出任何动作就退化成「当剧名搜」；搜不到只提示，不硬播。
