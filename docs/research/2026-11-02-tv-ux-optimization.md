# 电视端界面优化建议（重度使用者视角）

整理日期：2026-11-02。基线 v0.23.1+44，提交 `6291f68`。本文基于对 `MainActivity`、`HomeScreen`、`TvTools`、`TvDialog`、`PlaybackExtras`、`ThirdSourceScreen` 的只读审查，以及设置页真机截图的结构统计；**未修改代码，也未排期**。

结论：高频路径上最值得投入的是「播放中少按键」和「设置页少滚动」。收藏/历史的数据规模上来后，排序与批量管理比继续堆功能更实用。

## 优先级总览

| 优先级 | 建议 | 主要收益 | 代码落点 |
| --- | --- | --- | --- |
| P0 | 播放统一快捷面板 | 播放中调清晰度/倍速/弹幕从多次进出降为一次 | `PlaybackExtras` 菜单键设置、播放器覆盖层 |
| P0 | 设置页分组折叠 + 常用置顶 + 恢复默认 | 从首页到「手机快传」由十余次下移降到 3～4 次 | `MainActivity.settings()` |
| P0 | 收藏/历史排序切换与批量管理 | 数百条收藏时定位与清理成本大幅下降 | 收藏页/最近观看页头部与列表 |
| P1 | 「接着看」卡片信息增强 | 不必先打开详情就能决定看哪一集 | 首页 shelf 卡片 |
| P1 | 播放 OSD 常驻小标 | 随时确认当前清晰度、倍速、弹幕状态 | 播放器覆盖层 |
| P1 | 列表预取与长按连发 | 减少「滚到底才加载」和逐格挪动 | `maybeLoadMore()`、列表按键处理 |
| P2 | 快传弹窗倒计时与刷新地址 | 会话过期时不必关掉重开 | `TvTools.quickTransfer()` |
| P2 | 搜索历史单条管理、结果排序 | 高频搜索时快速重搜与筛选 | 搜索页 |
| P2 | 字号档位与焦点描边对比度 | 远距离/弱视观看更清晰 | `TvDialog`、`TvStyle` |

## P0-1 播放统一快捷面板

**代码事实**：播放中按菜单键只能绑定一种行为，取值限于「播放设置面板 / 选集 / 弹幕开关」（`PlaybackExtras.kt:42-45`）。想同时改清晰度、倍速并关弹幕，需要多次进出面板或改设置。

**建议**：长按菜单键弹出「播放快捷面板」，一屏内提供清晰度、倍速、弹幕开关、跳过片头片尾、字幕/音轨；短按仍执行用户当前选择，不改变既有习惯。面板操作后立即回写播放器，不中断播放。

**成本与风险**：需要播放器与三方源播放器（`ThirdSourceScreen.kt:325-364`）共用同一套面板；长按与短按的判定要走 `KeyEvent` 的重复计数，遥控器厂商差异需要真机回归。

**验收**：真机连续调 1080P→720P、1×→1.5×、关弹幕后继续播放不掉帧；单次长按只弹一次面板。

## P0-2 设置页瘦身

**代码事实**：设置页由 `settings()` 单页平铺（`MainActivity.kt:1353`），只有「播放偏好」「片单与设备」两个标题分组（`1378-1379`），条目已增至 19 项，含「手机快传」（`1494`）、「快传文件」（`1484`）、「导航模块」（`1510`）等。真机实测从「默认清晰度」到「手机快传」需十余次下移。

**建议**：
1. 两组改为可折叠，记住上次展开状态；
2. 「手机快传 / 快传文件 / 备份恢复」提到「常用」组并置顶；
3. 底部增加「恢复默认设置」，对可逆项生效，二次确认。

**成本与风险**：只涉及布局与本地偏好，不改数据结构；折叠状态需要额外持久化键，避免重启后全部展开。

**验收**：从首页按 `设置 → 下移 3 次` 内可到「手机快传」；折叠状态重启后保持。

## P0-3 收藏/最近观看排序与批量

**代码事实**：收藏页头部动作是「检查更新 + 分组筛选」（`MainActivity.kt:881-920`），最近观看是「管理记录 / 清空记录」；两者都没有排序切换，也没有多选删除。收藏上限 500、历史上限 200，重度用户会接近上限。

**建议**：加排序切换（最近更新 / 最近观看 / 名称 / 类型）；收藏页增加「管理」模式，用多选 + 确认批量移除，替代逐条右移到「删除」。

**成本与风险**：排序只需在渲染前对内存列表排序，不落盘；批量删除要保证焦点落在相邻条目，且与现有分组筛选、隐藏推荐互不干扰。

**验收**：500 条收藏切换排序无卡顿；批量删除 10 条后焦点仍在相邻卡，重启后数据一致。

## P1-1 「接着看」信息增强

**代码事实**：首页「接着看」只取最近 8 条（`MainActivity.kt:1262-1265`），其余进入「查看全部」；长按已有快捷操作，包含「管理观看记录」（`1297-1311`）。

**建议**：卡片上补一行文字信息「第 X 集 · 还剩 Y 分钟」，并把排序从单纯时间改为「最近看过优先、同剧连续」；这样不必先打开详情页。

**成本与风险**：`HomeScreen` 卡片布局需要多一行 meta，避免挤压标题跑马灯；数据已在 `BackupProgress` 里，无需新存储。

**验收**：首页 8 张卡均显示集数与剩余时长；已看至 90% 的剧不出现在「接着看」。

## P1-2 播放 OSD 小标

**建议**：播放覆盖层角落常驻 `1080P · 1.5× · 弹幕关`，操作后 3 秒淡出，不长期遮挡字幕区域。

**成本与风险**：仅 UI；需与现有覆盖层的显示/隐藏计时合并，避免与暂停提示互相覆盖。

**验收**：切清晰度与倍速后 3 秒内可见新值，字幕区不被遮挡。

## P1-3 列表预取与长按连发

**代码事实**：分页在滚动到底部时触发（`MainActivity.kt:1080-1123`）；首页封面只加载焦点附近（`HomeScreen.kt:183-224`）。

**建议**：提前一屏预取下一页；方向键长按连续移动时加速，并保持焦点不丢失。

**成本与风险**：预取会提前发起网络请求，需保留失败重试与过期校验；长按连发要避免与横向滚动/详情跳转冲突。

**验收**：快速下移至列表末尾时不再出现空白等待；长按 2 秒可跨越 20 张卡。

## P2 其他

- **快传弹窗**：`TvTools.quickTransfer()`（`TvTools.kt:278`）增加剩余时间倒计时与「刷新地址」，会话过期可原地重建，不必关闭重开；「快传文件」补批量删除与总占用统计。
- **搜索页**：手机扫码输入已具备（`MainActivity.kt:700-760`、`TvTools.kt:155-180`）；建议补搜索历史单条删除与结果排序（类型/时长），空结果给出换片源引导。
- **可读性**：全局字号档位、焦点描边对比度，远距离观看更友好。
