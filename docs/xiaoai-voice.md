# 小爱同学语音开播（巴法云中转）

> 状态（2026-11-10）：本文描述的是**可选的自建链路**（巴法云中转），不是小爱官方技能集成；是否搭建由用户自行决定。应用内用户可见文案已不再主动提及小爱同学（避免误导未配置该链路的用户），电视端的巴法云私钥入口与指令处理保留。

电视端从 `0.28.15-xiaoai` 起内置这条链路，**不需要 NAS、不需要 Home Assistant、不需要改路由器**。

```
小爱音箱 → 米家（我的 → 其他平台设备 → 巴法）→ 巴法云 → 电视（每 2 秒拉一次主题列表）
```

## 为什么是巴法云

小爱只会说「打开 X / 关闭 X」，它不会把一句话原样传出来，米家也不允许第三方 App 把自己塞进去当设备。
米家原生支持绑定**巴法云账号**，绑完以后巴法里的主题会以「设备」的身份出现在米家，小爱就能直接喊它的名字。
这是目前唯一既不要企业资质、又不用加硬件的一条路。

于是约定：**一个主题 = 一个动作，主题昵称 = 小爱要喊的名字**。

## 一次配置（10 分钟）

1. **注册巴法云**：<https://cloud.bemfa.com> —— 用**手机号或邮箱**注册，别用微信扫码（扫码注册的账号接不了米家）。
2. **拿私钥**：登录后控制台首页那串 32 位十六进制，就是私钥（本文里的事都靠它）。

   > 它既是 MQTT 的 clientID，也代表账号，只存在电视本机；界面里只显示 `前4…后4`。
3. **建主题**：让每部想看的剧、每个想跳的模块各占一个主题。

   | 主题名 | 昵称（小爱喊的就是它） | 效果 |
   |---|---|---|
   | `hgplay1...001` | `黄石第五季` | 按名字搜并起播（有进度就续播） |
   | `hgplay2...001` | `文盲修仙` | 同上，另一部 |
   | `hgmod1...001` | `红果片源` | 跳到片源模块 |
   | `hgmod2...001` | `红果首页` | 回到首页 |

   规则：
   - **主题名只能用字母数字**，且必须以 `hg` 开头（电视只认这个前缀，免得把你别的巴法设备当成指令）；
   - **末三位是设备类型**：`001` 插座、`002` 灯泡、`006` 开关…… 不写后缀的主题不会同步到米家，`001` 最稳；
   - 昵称可以随便写中文，进主题的「更多设置」里改。
4. **同步到米家**：米家 App → 我的 → 其他平台设备 → 右上角添加 → 找到「巴法」→ 登录同一账号。
   这些设备只出现在「其他平台设备 → 巴法」里，不会进米家首页，这是正常的。
5. **电视上填私钥**：设置 → 设备与数据 → 小爱同学 → 扫码填写（用手机输入，不用遥控器敲 32 位）。
   状态显示「已连接 · N 个设备」就成了。

之后直接说：**「小爱同学，打开黄石第五季」**。

## 容易卡住的地方

- **巴法 App 里的「+ / 添加设备」不是这个入口**：那是最配网（输 WiFi 密码、搜硬件），没有实体硬件会一直卡在搜索。
  主题只能在**网页控制台**建：<https://cloud.bemfa.com> → MQTT 设备云 → 添加设备 → 选「自定义主题」→ 填主题名。
- **主题名的末三位决定米家里的身份**：`001` 插座、`002` 灯泡、`006` 开关。不带后缀的主题不会同步到米家，所以统一用 `001`。
- **改昵称**：控制台主题行右侧「更多设置」→ 昵称，保存即可；改完要去米家点一次「同步设备」。
- 先建**一个**主题测通再批量加，别一上来建十个（免费版有主题数上限）。

## 昵称怎么解析

先剥掉 `红果` / `红果TV` / `hongguo` 前缀和两端的装饰符，再看剩下的：

- 正好是模块名 → 跳模块：`首页`、`搜索`、`排行榜`、`收藏`、`最近观看`、`片源`、`本地库`、`设置`
- 其它（两个字以上）→ 当剧名去搜
- 只有一个字 → 不响应，避免「看」这种昵称乱触发

所以 `红果黄石第五季` 和 `黄石第五季` 等价；`红果片源` 跳模块，`片源` 也一样。

## 想喊任意剧名：走小爱技能，不要指望米家

米家这条路的天花板在协议里：它给第三方设备下发的指令只有「开 / 关」，**没有任何字段能装一段
文本**。所以「一个语音名 = 一个动作」不是实现偷懒，是这条链路能表达的全部。想要「随便说出什么
片名都能搜」，只能换入口：**小爱开放平台的自定义技能**。

小爱技能会把用户说的原话（`query`）原样发给你的服务端，于是任意片名都能拿到；服务端跑在小米
自己的「函数计算」里，不用买服务器、不用域名、不用内网穿透。平台侧步骤和代码见
[`scripts/xiaoai-skill`](../scripts/xiaoai-skill/README.md)。

数据怎么流动：

```
小爱音箱 ──语音──▶ 小爱技能（小米云函数 main.py）
                        │  把片名 POST 进巴法云主题的 msg
                        ▼
                  巴法云 hgplay1001 ──MQTT──▶ 电视：搜索并起播
```

关键在于**巴法云的 `msg` 字段接受任意文本**（实测推 `黄石第五季` 云端原样保留）。所以电视端
不用区分两条路，只按载荷内容分流：

- 载荷是 `on` / `off` / `toggle` → 老逻辑，按**主题昵称**解释成剧名或模块（米家只能发这个）
- 载荷是别的文本 → 直接当**搜索词**（技能把片名写进来）

两条通道（MQTT 和轮询兜底）都要认这个分流，否则 MQTT 一断就只能喊固定昵称了。

## 语音控制整个 App（2026-11 起）

从 `0.29.x` 开始，电视端不再只认「剧名」——**说的整句话先过 `core/VoiceIntent` 解析**，
能确定就执行对应动作，认不出才退回「当剧名去搜」。

> 完整说法清单（含每个动作的全部别名、参数与回执）见 **[voice-cheatsheet.md](voice-cheatsheet.md)**，
> 那份由 `scripts/gen-voice-cheatsheet.py` 从代码导出，改词表后重新生成即可。

所以同一句话能干的事：

- 「检查版本是否有更新」「有没有新版本」→ 打开更新面板并立即查
- 「我要看历史记录第二个」→ 定位最近观看第 2 条并续播（`list.play history:2`）
- 「我要接着看」→ 续播最近一条
- 「进去排行榜」「打开设置」「打开片源」→ 跳模块
- 「切换主题背景」「换成白的」「夜间模式」→ 切主题
- 「下一集」「暂停」「继续播放」「关掉弹幕」「自动连播」→ 播放控制与偏好开关
- 「清理缓存」「观看统计」「备份」「手机快传」「遥控地址」「登录红果账户」→ 工具类弹窗

从 `0.30.4` 起新增一批（回执与真机验证都过）：

- **剧名 + 集数**：「我要看文盲修仙的第七集」→ 搜到后**直接落到第 7 集**（说了集号意图才够明确）
- **进度定位**：「快进30秒」「快退一分钟」「后退十五秒」；只说「快进」按 15 秒走，上限 10 分钟
- **返回**：「返回上一级」「返回」→ 等价遥控器返回键（有弹窗先关弹窗）；「返回首页」仍是跳模块
- **倍速**：「1.5倍速」「两倍速」→ 落到最近档位；「快一点」「慢一点」加减一档（播放页只影响本剧）
- **音量**：「声音大一点 / 小一点」调系统媒体音量；「静音」「取消静音」——播放中走播放器静音
  （遥控快照同步显示），没在播放走系统静音
- **定时**：「半小时后关掉」「定时30分钟」「看完这集就关」→ 定时停止
- **推荐与类型**：「给我随机推荐一部漫剧」→ 从首页推荐随机取一部**打开详情页**（不直接播）；
  「切换短剧」「看漫剧」「切换AI剧」→ 换内容分库
- **播放页**：「打开选集」「从头播放」「退出播放」「跳过片头」

从 `0.30.5` 起新增快传与搜索历史（真机验证都过）：

- **刷新二维码**：「刷新二维码」「换个二维码」→ 打开/重开手机快传面板，生成一张新码
  （没开面板时效果就是打开面板：新码本来就要重新生成）
- **快传文件**：「打开快传文件」「快传文件」→ 打开已收文件列表；列表里确认键
  按类型安装 / 预览 / 播放。注意它比「手机快传」优先——说「看文件」不该再弹一张码
- **清空文件**：「清空文件」「清空快传文件」→ 直接删掉快传收到的全部文件并回执
  「已清空 N 个，腾出 X」。**不弹二次确认**——话说出口就是确认，语音入口再让人
  摸遥控器按一次就白做了；删的只是快传文件，收藏、观看记录、已装应用都不动
- **清空搜索历史**：「清空搜索历史」「清空历史记录」→ 主站和片源各存一份搜索词，
  一句话两边一起清；停在搜索页会当场重绘（左栏历史块消失）

设计原则（改代码前必读）：

1. **能确定才执行，认不出就什么都不做**。每一步匹配不上就往下退：
   剧名+集数 → 列表+序数 → 快进快退 → 倍速 → 定时 → 动作词表 → 模块导航 → 返回 → 模糊兜底 → 剧名。
   模糊兜底要求别名的每个字都被句子覆盖、且两个动作不并列得分——并列意味着这句话真的有两种解释。
2. **搜索只出结果，不替人挑**。喊剧名（没说集号）一律停在搜索结果页让人自己点；
   片源模块同理。只有「说清了集号」和小爱「主题昵称就是剧名」这两条老路才自动起播。
   《八倍镜》《三倍人生》这类片名有专门的排除规则，不会被当倍速。
3. **动作范围 = 白名单**。`core/REMOTE_ACTIONS` 里登记一个键，界面层在
   `MainActivity.remoteAct` 接一下，语音立刻可用；协议入口做白名单与参数校验
   （`actArgValid`，参数只许小写字母数字与 `: . _ -`；`type.set`/`sleep.set`/`volume.mute`
   还有各自的参数格式校验）。
   新增语音词不用动 `VoiceIntent` 以外的任何解析逻辑。
4. **清洗只在电视端做**。小爱技能脚本只负责把原话转发进巴法云（见 `scripts/xiaoai-skill/main.py`
   顶部说明）：电视知道当前在哪一屏、列表里有什么，云端只有一句话，剥词只会丢信息。
5. **「第 N 季」不是序号**。《黄石第五季》不能被当成「第五个」——`VoiceIntent.ordinalOf`
   对后面紧跟「季」的匹配直接跳过；没有列表语境时序号必须占满整句才当定位用。
6. **每个动作有自己的回执**（Toast「已切换弹幕」之类），做不到时上层补一句
   「当前页面做不到」，不静默失败。

验收路径（不用等小爱）：局域网直接 POST `{"cmd":"act","id":"...","arg":"..."}` 到遥控地址即可，
和小爱进来的是同一条命令通道；整句走 `{"cmd":"say","text":"..."}`。
「遥控地址」弹窗里附了最常用的示例。

## 别人想用？各自接各自的，互不影响

这套链路的隔离是架构自带的，不靠约定：

- **电视只听自己的私钥**。订阅哪些主题、拉取哪些消息，全部由「实验室 → 小爱同学」里填的
  巴法私钥决定（`XiaoAiAccess.uid`）。别人的主题、别人的指令，这台电视看不见。
- **私钥是唯一凭据**。它既是 MQTT 的 clientID 也是 HTTP 接口的鉴权——所以反过来，
  谁拿到你的私钥谁就能遥控你的电视。**别外传私钥，也别把填了自己私钥的截图发出去。**
- **技能不能共用**。小爱技能里写死了转发目标（`main.py` 的 `UID`/`TOPIC`），指向谁的主题
  就只控制谁的电视。别人想用任意剧名，要自己在小爱开放平台建技能，把 `UID` 换成自己的。

所以别人要接入**自己的**电视，照下面的清单走一遍（每项都是免费公开服务）：

1. 电视侧载本 App，在「实验室 → 小爱同学」里填**他自己的**巴法私钥；
2. 注册巴法云（bemfa.com），控制台建 `hg` 开头的 outlet 主题，昵称写剧名；
3. 米家绑定（固定剧名开播，最简单、不用建技能）；想要任意话术 + 任意指令，
   再照上面小爱技能一节自建技能，`main.py` 里 `UID` 换成他的私钥。

三户人家各自一套私钥 + 各自一套主题 + 各自的技能，互相完全看不见对方，也不存在
「喊一句话控制到别人家电视」的路径。

## 边界

- **电视上的红果TV要在前台**：轮询只在 Activity 可见时跑（`onStop` 就停）。后台常驻会被系统掐，且费流量。
- **延迟 0–2 秒**：2 秒一轮，换来的是断网、待机、进程重启都不用重连状态机。
- **走云端**：小爱识别本来就在小米云，指令再经巴法云，整条链路出域。私钥泄露等于别人能遥控你的电视，别外传。
- **米家不能改名**：「其他平台设备」里设备名来自上游，要改名就回巴法控制台改昵称（再点一次同步）。
- **`watch` 找不到就只在电视上提示**，不会瞎播第一条。
- **`watch` 默认只出结果**：搜到后停在结果页让人自己点（说清集号才直接落到那一集）；
  当前内容库搜不到会自动换另一个库（漫剧/短剧）再搜一次。
- 想加一部新剧：巴法云加一个 `hgplayN001` 主题 + 改昵称 + 米家同步一次，不用动电视。
  （嫌烦就走上面的小爱技能，一次配好，之后不用再加主题）
- **片名带季号常常搜不到**：主站搜索按基名索引，所以语音搜索失败时会去掉「第 N 季 / 第 N 部」
  再搜一次（`ThirdCms.seriesBase`）。基名也搜不到就停在搜索页，不会乱播。

## 实现备忘（改这块代码前先看）

- **电视必须连一条 MQTT 长连接**（`bemfa.com:9501`，clientID = 私钥，订阅自己的 `hg` 主题）。
  米家下发指令前会先看设备在不在线，而巴法云的「在线」= 有客户端订阅了这个主题。只轮询 HTTP
  的电视永远算离线，小爱会直接回「设备不在线」——**指令根本不会发出来**，轮询再好也没用。
- **通配符订阅 `hg#` 会被拒**（SUBACK 返回 0x80），只能逐个订阅；新加主题要重新订阅，
  所以电视在线时每 60 秒还会拉一次列表刷新映射。
- **MQTT 的消息里只有主题名，没有昵称**，昵称得靠 `allTopic` 拉回来做映射。
- **`allTopic` 返回的主题数组在 `data.data` 里**，外面还包一层对象；文档写的是 `data` 直接是数组。
  两种都兼容，见 `XiaoAiVoice.parse`。
- **判「有新指令」靠 `unix` 比上次新**，再看载荷内容：`on` 走昵称、其它文本当搜索词。
  实测推送之后 msg 与 unix 都会更新，第一轮只记基线不执行，所以不会开机就自动播放。
  MQTT 与轮询双通道要去重，否则同一条指令会播两遍。
- **主站搜索对不认识的词不返回空，而是给一批热门推荐**，所以「一句话开播」拿到结果后必须过标题匹配
  （`TitleMatch`：完全相同 → 标题含关键词 → 关键词含标题），对不上就停在搜索页提示，绝不取首条硬播。
  这条是踩出来的：喊「黄石第五季」曾经播出过《1000集让我留下来了》。

## 和另外两条路的关系

| 方案 | 需要什么 | 自由度 |
|---|---|---|
| 巴法云（本文） | 只需小爱 + 电视 | 一个语音名 = 一个动作 |
| **小爱技能 + 巴法云**（[`scripts/xiaoai-skill`](../scripts/xiaoai-skill/README.md)） | 小爱开放平台实名认证（个人即可） | **任意剧名**，两句唤醒 |
| [`scripts/voice-bridge`](../../scripts/voice-bridge/README.md) | 一台常开的主机跑 Python | 一句话自由解析（「我想看…」「打开…」） |
| 中枢网关「虚拟事件」+ Home Assistant | 中枢网关 + 一台跑 HA 的主机 | 事件名可以带任意文本，最灵活 |

三条路都落到同两条遥控命令：`{"cmd":"watch","query":…,"episode":…}` 和 `{"cmd":"open","module":…}`，
整句指令也可以走 `{"cmd":"say","text":…}` 让电视自己理解。
