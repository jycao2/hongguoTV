# 红果TV UI 设计规范（v1.0 · 2026-11-25）

本规范是**全系统**的视觉与交互契约：所有页面（首页 / 分类 / 搜索 / 详情 / 播放器 / 设置 / 快传 / 遥控 / 本地库 / 片源 / 我的 / 全部弹窗）必须遵守。
代码入口：`TvStyle`（令牌）、`TvComponents`（行项/开关/按钮）、`TvDialog`（弹窗）。改动视觉必须先改令牌，禁止在页面里写死颜色/尺寸。

---

## 1. 设计原则

1. **十英尺界面**：用户坐在 2-3 米外看电视。所有可交互元素最小高度 ≥ 36dp，正文 ≥ 13sp，焦点态必须一眼可辨。
2. **焦点即指针**：遥控器唯一的「光标」是焦点框。焦点态 = raised 底 + 2dp accent 描边 + 文字提亮，全系统唯一形态，禁止自创。
3. **令牌优先**：颜色、字号、间距、圆角一律取自 TvStyle 令牌；新视觉先加令牌再使用。
4. **信息左右分离**：列表行 = 左侧名称、右侧值/开关/箭头。值永远右对齐、muted 色，不与名称混排。
5. **两级主题**：NIGHT（深夜影院）/ PORCELAIN（暖玉白）。任何组件两套主题都要可读，禁止只调一套。

---

## 2. 色彩令牌（TvStyle）

| 令牌 | NIGHT | PORCELAIN | 用途 |
|---|---|---|---|
| `background` / `bg` | #0B0F15 | #E2D9C8 | 页面底 |
| `surface` | #171E28 | #FFFFFF | 卡片、行项、弹窗底 |
| `raised` | #202A36 | #F3ECE0 | 焦点底色、浮起卡片 |
| `accent` | #FF8964 | #C4532E | 焦点描边、选中、主按钮、强调 |
| `gold` | #FFC46B | #A6681C | 次强调：元信息、播放状态标 |
| `text` / `white` | #F3F4F6 | #3A342C | 主文字 |
| `muted` | #93A0B2 | #8B7D6B | 次文字、值、说明 |
| `outline` | #2B3746 | #CEC3B0 | 描边、分隔 |
| `selectedSurface` | #3D2722 | #E0CEBC | 选中态底（当前项） |
| `badgeSurface` | #1C1F27 | #50463C | 角标底 |
| `danger` | #E85656 | #C43C3C | 危险操作、错误 |

**语义规则**：
- 焦点/选中/主操作只有 accent 一个色，禁止给普通元素引入新彩色。
- 「成功」用 #4CAF50（两主题同值），只用于状态反馈点（接口自检等），不做大面积填充。
- 危险（不可逆删除/关闭保护）只允许 `danger` 色，且确认按钮红底白字。
- 透明 > 新颜色：能用层次（surface/raised）表达的就不用新色。

---

## 3. 字号与字重（全局唯一刻度）

| 级别 | sp | 字重 | 用途 |
|---|---|---|---|
| display | 25 | medium | 页面大标题（设置/我的页头） |
| title | 20 | bold | 弹窗标题 |
| heading | 18 | medium | 区块标题（设置分类标题） |
| body | 15 | normal | 行项名称、按钮、正文选项 |
| caption | 13 | normal | 说明、副标题、紧凑按钮 |
| micro | 11 | normal | 页脚、法务、角标 |

规则：正文一律 `includeFontPadding=false`；标题用 `sans-serif-medium`；焦点态可加粗（button 类），行项类不加粗只换底色。

---

## 4. 间距与圆角刻度

- **间距**（dp）：`4 / 8 / 12 / 16 / 20 / 24 / 28`。行内边距横向 16、纵向 12；区块间 16；弹窗内边距 28/24/28/20。
- **圆角**（dp）：`S=8`（小标签、点）、`M=12`（行项、卡片、按钮）、`L=16`（大卡片）、`XL=20`（弹窗）、`PILL`（胶囊=高的一半）。
- **高度**：行项 56dp（min 48）、标准按钮 44dp、紧凑按钮 36dp、导航 pill 36dp、开关 24dp。
- **海报比例**：`POSTER_ASPECT=0.7`，禁止改。

---

## 5. 焦点态（全系统唯一形态）

| 状态 | 底色 | 描边 | 文字 |
|---|---|---|---|
| 默认 | surface（导航类透明） | 无 | text/muted |
| 焦点 | raised | accent 2dp | white + 加粗（按钮类） |
| 选中 | selectedSurface | accent 2dp | accent |
| 焦点+选中 | raised | accent 2dp | accent |

实现统一走 `TvStyle.focusPainter(...)` 或 `focusStyle()`；弹窗选项走 `TvDialog.choose` 的 paint 逻辑。**新组件不得自创焦点样式。**

---

## 6. 组件规范

### 6.1 设置行 SettingRow（TvComponents）
- **结构**：左=名称（body 15sp, text 色）；右=值（caption 14sp→14sp muted，右对齐，max 2 行省略）或开关或「›」暗示。
- **尺寸**：宽 match，高 wrap（min 48dp），内边距 16/12，行间距 8dp。
- **变体**：
  - `action`：无值，整行可点（如「开源许可」）。右侧可带 muted 提示词。
  - `value`：名称 + 当前值（如「默认清晰度 · 1080P」→ 左「默认清晰度」右「1080P」）。
  - `toggle`：名称 + TvSwitch，整行点击等效拨开关。
  - `danger`：同 action，名称用 danger 色（如「清空历史」）。
- **可用性**：整行可聚焦可点击；值变化后必须同步刷新（`setValue`），禁止重排整页。

### 6.2 选项面板 SettingOptionPanel（TvComponents）
- **用途**：宽屏（≥840dp）设置页右栏，操作对象是中间列表的当前焦点项；窄屏不挂载，页面退回两栏（选择走弹窗）。**实验室功能 / 使用说明 / 关于红果三个分类不挂右栏**（全是弹窗动作与长文说明），隐藏第三栏退回两栏，右键不响应。
- **三种形态**：
  - **有选项** → 选项列表（Leanback 风，无圆点）：未选=透明底 muted 字；**选中=accent 粗体字 + 右侧 20dp accent 圆形对勾徽章（白 ✓，INVISIBLE 占位防文字跳动）**；焦点=raised 底+accent 描边（圆角 S）。可聚焦、上下浏览、确认键生效并实时刷新中栏值、左键返回中栏行。取代弹窗选择器。选项行 ≥44dp 高、内边距 14/13、行距 4。带「样例预览」性质的选择器（如屏保画面的跑马灯演示弹窗）不走右栏，保持原弹窗。
  - **开关行** → 状态卡片：surface 底+outline 细描边、圆角 M、高 ≥48dp，左「当前状态」muted 标签、右静态 TvSwitch 回显（不可操作，切换仍在中间列表按确认键），与中栏行左右布局同构。
  - **动作行 / 分类** → 不放假图标：说明 + 「按确认键打开 / 进入分类」提示。
- **结构**：标题（title 17sp medium）固定顶部 → 中间滚动区（说明 13sp muted 1.35 行距 + 选项列表/状态卡片，超高内部滚动，切换条目回顶）→ 细分隔线（outline）+ 操作提示（12sp muted）**固定底部**。容器 surface 底、圆角 L(16)、内边距 20，自身不可聚焦，只有选项行可聚焦。
- **焦点链**：中栏行 →(右，几何搜索)→ 选项列（落点=当前选中项）；选项 →(左)→ 回中栏行；选项列内部上下自环（首末不再越界）。带选项的行在中间列表按确认=进右栏（不再弹窗）。
- **实现纪律**：labels/selectedIndex 绑定时现取（值可能刚被改过）；选中标记由 `repaintOptions` 统一画，焦点变化必须重调（选项行 onFocusChange 里调）；容器与内容宽度必须 MATCH_PARENT（wrap_content 容器会收窄 match_parent 子项）。

### 6.3 开关 TvSwitch
- 轨道 40×22dp 圆角 PILL，thumb 16dp；关=outline 轨+raised thumb，开=accent 轨+白 thumb；焦点态描边 accent 2dp。
- 状态文案（「开启/关闭」）不再写在行名称里，由开关本体表达；需要文字时放右侧值位。

### 6.4 按钮（TvDialog.capsuleButton）——原版胶囊样式（用户 2026-11-26 拍板回退）
- **平时**：surface 底 + outline 1dp 描边 + 正文字色，胶囊圆角 24。
- **焦点**：accent 实底 + accent 描边 + **背景色粗体字**（全系统焦点语言与中栏行一致）。
- **危险动作**（confirm danger）：确认按钮红底白字，焦点=亮红底+白描边；默认焦点仍停在「取消」。
- 高度 44（标准）/34（compact）；水平内边距 20/12；compact 用于单行 6 按钮的弹窗（清 minWidth，radiusDp 可调小防圆形化）。
- 不做多变体系统：主动作与次动作同款，靠焦点与文案区分；`TvComponents.pillButton` 变体体系已移除。

### 6.5 弹窗（TvDialog）——统一四种尺寸
| 尺寸 | 宽度 | 用途 |
|---|---|---|
| S | 360dp | 确认框（confirm）、短提示 |
| M | 460dp | 信息弹窗（info）、单列选择（choose 默认）、二维码 |
| L | 560dp | 表单、列表管理（快传文件、屏保素材） |
| XL | 640dp | 双栏内容（帮助抽屉、接口自检） |

- 宽度仍受屏幕 92% 上限压缩；内容自然宽度小于尺寸时**弹窗不缩**（尺寸即承诺，视觉稳定）。
- 高度上限：S/M 65% 屏高、L/XL 60%；超出由正文滚动区消化，标题/按钮恒在屏内。
- 结构固定：标题（title 20 bold）→ 正文/滚动区（15sp muted，1.25 行距）→ 按钮行（右对齐，主按钮在最右）。
- 所有 AlertDialog 必须经 TvDialog 创建/登记（遥控可达）；禁止页面自建 AlertDialog。

### 6.6 导航
- 顶栏 pill（pillNav）：高 36（compact 32），图标+文字；选中=accent 边框透明底+accent 文字，焦点=raised+accent 边框。
- 设置侧栏（rail）：与顶栏同一焦点语言，宽度 236dp。

### 6.7 列表与卡片
- 内容卡片：surface 底、圆角 L(16)、无描边；焦点卡片 raised+accent 2dp。
- 选中项（当前值/当前源）：selectedSurface 底 + accent 文字，不加粗。
- 网格间距 12dp；横向列表行高按内容，纵向列表行 ≥ 46dp。

---

## 7. 文案规则
- 「名称 · 值」结构在行项里拆开呈现（名称左、值右），在 HUD 等单行按钮里可保留整串。
- 开关行不带「· 开启/关闭」后缀；数量/规格值保留单位（「3 个」「45 分钟」「1080P」）。
- 危险动作文案写具体（「清空全部」「删除备份」），不写「确认」。

---

## 8. 动效与反馈
- 焦点移动零动画（电视低延迟优先）；弹窗带系统默认渐入，锚点弹窗禁用窗口动画（防「飞入」错觉）。
- Toast 用于轻反馈；需要用户确认的反馈走 TvDialog。
- 屏幕触摸后进入触摸模式不影响焦点可用性：所有可点元素 `isFocusableInTouchMode=true`（沿用现有约定）。

---

## 9. 落地与守护
- 新 UI 一律用组件，不手写 GradientDrawable 状态（焦点态除外，走 TvStyle.focusPainter）。
- 评审 checklist：焦点是否唯一形态？两主题是否都过？值右对齐了吗？主按钮唯一吗？弹窗尺寸选对了吗？
