# 更新日志

本文件记录红果 TV 面向使用者的改动。版本号为 Android `versionName`，括号内为 `versionCode`。

## v0.30.10 — 2026-11-08

双构建收尾自动更新链路（0.30.9 的清单修对了，但安装仍被拦）。

- **0.28.0 客户端装前校验真相**：`AppUpdater.validateApk` 要求更新包**实际 minSdkVersion == 清单声明 minSdk**（报错文案「新版包名、版本或签名不匹配」有误导性，真机截图逐项核对后定位）。0.30.9 声明 26、实际 21，必然拦下。
- **双构建方案**：更新通道 `-android8.apk` 实际 minSdk 26（与声明一致，存量用户全通）；Release 页另挂 `-android5.apk`（minSdk 21，Android 5-7 新用户手动装）。`minSdk` 改由 Gradle 属性 `HONGGUOTV_MIN_SDK` 控制，默认 26。
- **CI 防呆**：发布前用 aapt2 校验两包实际 minSdk 分别为 26/21，不符即失败。

## v0.30.9 — 2026-11-08

紧急修 0.30.8 的自动更新链路。

- **存量客户端收不到更新（严重）**：0.30.8 的更新清单改用 `-android5.apk` 命名、声明 `minSdk: 21`，而 0.28.0 及更早的解析器要求 `-android8.apk` 且 `minSdk ∈ 26..100`——存量用户点检查更新只会看到「更新信息格式不正确@gh-proxy.com」，永远拿不到新版本。真机在 0.28.0 上复现。
- **修法**：发布侧恢复 `-android8.apk` 命名、清单声明 `minSdk: 26`（实际包仍是 21，声明值只用于旧客户端判断，现存用户都在 Android 8+，不会拦人）；客户端侧放宽为 `android[58]` 两种命名都接受，并补单测锁住。
- 顺带把「更新信息格式不正确」的排查路径写进本文档：先 `curl` 镜像确认返回的是不是合法 JSON，再对齐发布脚本的命名与 minSdk 声明。

## v0.30.8+52（10452）— 2026-11-08

自 v0.28.0 之后这一轮迭代的合并说明。中间版本未单独发布，统一并入本条。
云端正式包：[kotlin-v0.30.8-build.52](https://github.com/jycao2/hongguoTV/releases/tag/kotlin-v0.30.8-build.52)，`versionCode` 基准由 10200 抬到 10400（本机调试包已到 10337，不抬会让电视判定「不是更新」）。

### 语音遥控（新增）

- 遥控页新增「一句话直达」：输入剧名直接开播或停在详情页，输入指令直接执行，回执以 Toast 播报。
- 说法覆盖到 47 种，动作白名单 41 个键、8 个模块，完整清单见 [语音指令速查表](voice-cheatsheet.md)。
- 支持的说法举例：`我要看文盲修仙的第七集`、`快进30秒`、`后退15秒`、`1.5倍速`、`返回上一级`、`给我随机推荐一部漫剧`、`登录红果账户`、`打开选集`、`跳到片尾`、`静音`、`音量加`、`半小时后关掉`、`切到短剧`。
- 搜索改为只列结果：说剧名不再自动播放，把结果摆出来由人自己点；只有说清集数才直达那一集。
- 当前库搜不到时自动换库（漫剧 / 短剧）重搜一次。
- 快传与搜索历史接入语音：`刷新二维码`、`打开快传文件`、`清空文件`、`清空搜索历史`。
- 电视内置小爱语音入口（巴法云中转），电视常连 MQTT，修掉了「设备不在线」；支持多用户各自接入、互相隔离。
- 静音优先作用于播放器，播放页内状态可直接同步。

### 鼠标操作（新增）

- 播放页进度条支持鼠标拖动：轨道 4dp、可点区 26dp，拖动时暂停自动刷新，松手精确 seek，条上滚轮 ±10 秒。
- 播放页右上角新增「✕ 退出」，鼠标右键也可退出播放。
- 「✕ 退出」与鼠标手势提示只在最近一次操作来自鼠标时出现，按遥控键立即收起——TCL 的红外鼠标棒会被系统伪装成触摸屏，因此按事件来源判断，不按插着什么设备判断。
- 鼠标上下滑动换集方向修正：上滑下一集、下滑上一集（此前慢速拖动方向相反，快速甩动正常）。

### 播放与片源

- 修复片源播放接口 110001：迁移到新的五头签名。
- 片源不兼容面板补「播放上一集」；降级模型补诊断标记与多轮重试。
- 聚合搜索加 8 秒总时限：到点放弃未返回的慢源，已到的结果立即展示并标明超时源，不再永远停在「正在聚合 1/6」。
- 片源详情加系列剧切换条。
- 没有可播剧集时停在搜索页让人手选，不再乱播。

### 遥控页（手机浏览器）

- 全屏与横屏：全屏不再被浏览器掰成横向、保留退出按钮、横屏视口改两栏、横屏选集改多列、长片名不再撑宽卡片、横屏全量记录弹层不再一屏两张巨图。
- 横屏内容可滚动不再丢卡片；失联页说明不再压住重试按钮。
- 去掉全屏里的转屏按钮。
- 遥控地址弹窗补完整调用示例，附语音与自动化桥。

### 界面与焦点

- 排行榜新增「上新」子视图，时间窗改为弹层，页头焦点链补齐。
- 详情页：翻页后焦点保持在翻页按钮上；修复多季剧跳季后丢失其它季。
- 修复详情页剧名里混进简介、标题栏第二行被裁成半截。
- 信息弹窗高度封顶，遥控器上下键直接翻正文。
- 设置页新增「实验室功能」分组。
- **触摸模式下返回键失灵（重点修复）**：鼠标棒点击会让窗口进入触摸模式，此时首页胶囊按钮无法取得焦点，返回键静默失效、卡在卡片上。已给胶囊按钮与弹窗按钮补触摸模式可聚焦属性，并在焦点回收失败时兜底弹出退出确认。

### 兼容性与稳定性

- `minSdk` 下探至 21（Android 5.0），修复低版本 API 越界崩溃。
- 修复重建后账号回调崩溃；手动检查更新不再受页面限制。
