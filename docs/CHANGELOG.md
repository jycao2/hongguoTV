# 更新日志

本文件记录红果 TV 面向使用者的改动。版本号为 Android `versionName`，括号内为 `versionCode`。

## 未发布

- **全档 bytevc2 片源自动换出兼容档**：部分剧集官方只下发 bytevc2 编码（电视无系统解码器，未带软解的包直接「片源不兼容」）。现在遇到全档 bytevc2 时自动按官方客户端兼容逻辑（`codec_type=0 + force_codec=h264`）重取一次，换出可硬解的 H.264/H.265 档直接播放；重取失败静默回落原有软解/提示路径，不触发限流冷却。真机已验证（全档 bytevc2 剧集换出 H.265 硬解连续播放 + 自动连播）。
- **详情页选集网格联动**：跳转集数、自动连播、遥控切集后返回详情页，选集网格现在自动翻到当前集所在页并高亮，不再停在旧页码；手动翻页浏览行为不变。

## v0.34.0 — 2026-11-24

- **恢复播放**：官方接口静默空响应定位为签名参数错误（F21 377→312），对齐上游现行协议修好，1080P 与 CENC 加密流正常可播；取址预算压到 2~5 发、限流冷却更保守。
- **起播与换剧提速**：渐进式填充 + 批量预热，切下一集约 343ms，自由刷剧首入 4.8s→1.8s；换剧文案改为「新剧载入中...」。
- **设置新增「使用说明」**：8 个主题的用法介绍与常见问题，遥控翻页阅读。
- **屏保**：新增「仿真时钟 · 墨金 / 晨白」两款表盘壁纸；时钟位置新增「居中」并支持预览联动。
- **最近观看**：本机记录默认折叠两行，「查看全部」卡展开全部，云端记录更快到达。
- **弹幕表情补全**：对照上游表格合并并经真实弹幕验证，不再有方框缺字。

## v0.33.1 — 2026-11-20

11-20 官方取址接口第二次变更，本版彻底恢复播放。

- **根因定性（修正 v0.33.0 的结论）**：官方改为只认真签名——v5 占位三头（`x-khronos`/`x-helios`/`x-medusa`）与真签名头同现、或单独出现，都会被当作伪造痕迹**静默丢弃**（HTTP 200 + 0 字节）。与请求密度、IP、身份、Cookie、版本号、路径全部无关，当天全天所有「换参数都空」的现象均由此而来。
- **修法**：播放取址全部改用真签名（fqapp 的 Argus/Ladon 移植，新增 `core/Argus.kt` 与 `PlayerSigner`）；签名头按最终 query（含穷举出的 `_rticket`）重新生成，x-khronos 与 `_rticket` 同源；取址路由优先级对齐官方客户端现行形态——真签名 GET `video_tab` 首选、POST `multi_video_model/v1` 兜底，请求参数（v1 路径、74532 版本号、完整 `biz_param`、`mixed_video_id_map`）同步对齐。
- **限流等待改进**：播放失败遇到限流（冷却 20→60→120→300 秒递增）时，界面显示倒计时并自动等待重试，不再消耗普通重试预算卡死在手动面板；冷却期内零请求，避免放大官方风控计数。

## v0.33.0 — 2026-11-20

官方播放接口变更导致无法播放，切换新链路恢复，并新增三个功能。

- **恢复播放**：官方把取址改判到 `/novel/player/multi_video_model/player/v1`（v5 签名 + `mixed_video_id_map`），本版切换过去，播放恢复。
- **首页新增自由刷剧**：接入个性化推荐流（`tab/v` / `cell/change`），播放页 ↑↓ 换剧、←→ 换集、确认进详情。
- **待机屏保**：空闲后自动盖屏，内置 4 种画面风格，可用手机传自己的图片视频做屏保，支持轮播间隔、角标时钟与立即预览。
- **传输与备份**：手机扫码迁移收藏与观看记录。
- **第三方片源失效自动切换**：失效时自动换到下一可用片源，播放不中断。
- **换集、换剧画面定格过渡**：抓取当前帧盖过渡层，等新一集渲染出首帧才撤掉，不再黑屏。

## v0.32.0 — 2026-11-16

恢复播放能力，并补全鼠标操作。

- **官方播放接口改判导致全部剧集无法播放（严重）**：11-16 起官方把播放接口的旧签名整族判废，所有第三方客户端同时失效（上游 `jackotom/hongguo-drama#162`、`N3urda/hongguoTV#59` 同日爆发）。排查确认与账号登录、Cookie、TLS 指纹、UA、版本号均无关——不是被风控拦，是签名体系换代。
- **修法**：取址路径改为 `/novel/player/multi_video_model/player/v1`（比旧路径多一段 `player`），签名改用 Android `v04.10.03`（v5），只发 `khronos` / `helios` / `medusa` 三个头，请求体 gzip。v5 要求 `iv(query, md5(body), ts) and 15 == 12` 命中后才接受，需预扫 ticket `0..1023` 挑选。新增 `V5Constants`（魔数 / license `646637794` / 签名主密钥 / 1024 字节替换盒）与 `MobilePlayback`，`AesV3` 增加 v5 表分支，`Signer` 新增 `hashF13V5` / `medusaV5` / `signPlaybackV5`。旧的 `video_tab` 与 `multi_video_model/v1` 路由保留为失败兜底。
- 实测非前 3 集的第 70 集取到 1080P，彻底摆脱官网游客「前 3/5 集」限制，无需登录、无需 Cookie。
- **鼠标右键动作可自定义（新增）**：播放中默认右键退出，可选「播放/暂停」「选集」「显隐控制条」「播放设置」；设置项仅在检测到真鼠标或触控板时出现（排除 `irtouch` 这类伪装成鼠标的红外触摸层）。第三方片源同步支持。
- **鼠标单击画面暂停/续播（新增）**：底部快捷按钮精简为「选集 · 收藏」，播放/暂停交给画面正中按钮。
- **三方片源 m3u8 广告过滤（新增）**：读取清单时剔除 `/video/adjump/` 广告分片及其 `EXTINF`，合并相邻 `DISCONTINUITY`，解析异常回退原始清单；附 7 个单元测试。
- **手机遥控标题超长横向滚动（改进）**：只有超出宽度才往返滚动，短标题保持静止；快照刷新不打断动画，切回遥控形态与旋转屏幕时按真实宽度重算。

## v0.31.1 — 2026-11-13

播放页鼠标操作补全，并修复倍速连播与榜单焦点问题。

- **播放页鼠标快捷按钮（新增）**：底部一行「播放 / 暂停 · 选集 · 收藏」，鼠标一动浮现、静止 3 秒收起，配色跟随系统主题；第三方片源播放器同步支持。
- **倍速连播音画不同步（修复）**：自动连播下一集时画面回 1 倍速、声音维持原倍速（极米 Z6X 复现）。无缝切集时 ExoPlayer 重建视频解码器后不继承播放参数，改在 `onMediaItemTransition` 显式重设倍速；NAS 本地库同样处理。
- **榜单鼠标焦点跳动（修复）**：鼠标滚轮只滚视口，不再补网格焦点、不主动滚动，消除与顶栏焦点来回争抢（issue #22.1）。
- **鼠标手势换集弹层（修复）**：上下滑换集不再弹控制条与按键提示，遥控器换集保留反馈（#22.2）。
- **网速悬浮不显示（修复）**：页面重建清空视图后旧引用失效，改为每次重新挂载。

## v0.30.10 — 2026-11-08

双构建收尾自动更新链路（0.30.9 的清单修对了，但安装仍被拦）。

- **0.28.0 客户端装前校验真相**：`AppUpdater.validateApk` 要求更新包**实际 minSdkVersion == 清单声明 minSdk**（报错文案「新版包名、版本或签名不匹配」有误导性，真机截图逐项核对后定位）。0.30.9 声明 26、实际 21，必然拦下。
- **双构建方案**：更新通道 `-android8.apk` 实际 minSdk 26（与声明一致，存量用户全通）；Release 页另挂 `-android5.apk`（minSdk 21，Android 5-7 新用户手动装）。`minSdk` 改由 Gradle 属性 `HONGGUOTV_MIN_SDK` 控制，默认 26。
- **CI 防呆**：发布前用 aapt2 校验两包实际 minSdk 分别为 26/21，不符即失败。

## v0.30.9 — 2026-11-08

紧急修 0.30.8 的自动更新链路。

- **存量客户端收不到更新（严重）**：0.30.8 的更新清单改用 `-android5.apk` 命名、声明 `minSdk: 21`，而 0.28.0 及更早的解析器要求 `-android8.apk` 且 `minSdk ∈ 26..100`——存量用户点检查更新只会看到「更新信息格式不正确@gh-proxy.com」，永远拿不到新版本。真机在 0.28.0 上复现。
- **修法**：发布侧恢复 `-android8.apk` 命名、清单声明 `minSdk: 26`（实际包仍是 21，声明值只用于旧客户端判断，现存用户都在 Android 8+，不会拦人）；客户端侧放宽为 `android[58]` 两种命名都接受，并补单测锁住。
- 顺带把「更新信息格式不正确」的排查路径写进本文档：先 `curl` 镜像确认返回的是不是合法 JSON，再对齐发布脚本的命名与 minSdk 声明。

## v0.30.8+52（10452）— 2026-11-08

自 v0.28.0 之后这一轮迭代的合并说明。中间版本未单独发布，统一并入本条。
云端正式包：[kotlin-v0.30.8-build.52](https://github.com/jycao2/hongguoTV/releases/tag/kotlin-v0.30.8-build.52)，`versionCode` 基准由 10200 抬到 10400（本机调试包已到 10337，不抬会让电视判定「不是更新」）。

### 语音遥控（新增）

- 遥控页新增「一句话直达」：输入剧名直接开播或停在详情页，输入指令直接执行，回执以 Toast 播报。
- 说法覆盖到 47 种，动作白名单 41 个键、8 个模块，完整清单见 [语音指令速查表](voice-cheatsheet.md)。
- 支持的说法举例：`我要看文盲修仙的第七集`、`快进30秒`、`后退15秒`、`1.5倍速`、`返回上一级`、`给我随机推荐一部漫剧`、`登录红果账户`、`打开选集`、`跳到片尾`、`静音`、`音量加`、`半小时后关掉`、`切到短剧`。
- 搜索改为只列结果：说剧名不再自动播放，把结果摆出来由人自己点；只有说清集数才直达那一集。
- 当前库搜不到时自动换库（漫剧 / 短剧）重搜一次。
- 快传与搜索历史接入语音：`刷新二维码`、`打开快传文件`、`清空文件`、`清空搜索历史`。
- 电视内置小爱语音入口（巴法云中转），电视常连 MQTT，修掉了「设备不在线」；支持多用户各自接入、互相隔离。
- 静音优先作用于播放器，播放页内状态可直接同步。

### 鼠标操作（新增）

- 播放页进度条支持鼠标拖动：轨道 4dp、可点区 26dp，拖动时暂停自动刷新，松手精确 seek，条上滚轮 ±10 秒。
- 播放页右上角新增「✕ 退出」，鼠标右键也可退出播放。
- 「✕ 退出」与鼠标手势提示只在最近一次操作来自鼠标时出现，按遥控键立即收起——TCL 的红外鼠标棒会被系统伪装成触摸屏，因此按事件来源判断，不按插着什么设备判断。
- 鼠标上下滑动换集方向修正：上滑下一集、下滑上一集（此前慢速拖动方向相反，快速甩动正常）。

### 播放与片源

- 修复片源播放接口 110001：迁移到新的五头签名。
- 片源不兼容面板补「播放上一集」；降级模型补诊断标记与多轮重试。
- 聚合搜索加 8 秒总时限：到点放弃未返回的慢源，已到的结果立即展示并标明超时源，不再永远停在「正在聚合 1/6」。
- 片源详情加系列剧切换条。
- 没有可播剧集时停在搜索页让人手选，不再乱播。

### 遥控页（手机浏览器）

- 全屏与横屏：全屏不再被浏览器掰成横向、保留退出按钮、横屏视口改两栏、横屏选集改多列、长片名不再撑宽卡片、横屏全量记录弹层不再一屏两张巨图。
- 横屏内容可滚动不再丢卡片；失联页说明不再压住重试按钮。
- 去掉全屏里的转屏按钮。
- 遥控地址弹窗补完整调用示例，附语音与自动化桥。

### 界面与焦点

- 排行榜新增「上新」子视图，时间窗改为弹层，页头焦点链补齐。
- 详情页：翻页后焦点保持在翻页按钮上；修复多季剧跳季后丢失其它季。
- 修复详情页剧名里混进简介、标题栏第二行被裁成半截。
- 信息弹窗高度封顶，遥控器上下键直接翻正文。
- 设置页新增「实验室功能」分组。
- **触摸模式下返回键失灵（重点修复）**：鼠标棒点击会让窗口进入触摸模式，此时首页胶囊按钮无法取得焦点，返回键静默失效、卡在卡片上。已给胶囊按钮与弹窗按钮补触摸模式可聚焦属性，并在焦点回收失败时兜底弹出退出确认。

### 兼容性与稳定性

- `minSdk` 下探至 21（Android 5.0），修复低版本 API 越界崩溃。
- 修复重建后账号回调崩溃；手动检查更新不再受页面限制。
