# 本地库 · 文件名识别规则清单

- 日期：2026-11-04
- 适用范围：本地库（NAS/WebDAV）一期
- 原则：**宁可识别不出来，也不识别错**。识别失败一律降级为「文件列表直选」，不做臆测。
- 实现位置：`core` 模块 `NasLibrary`（纯 Kotlin，全部规则配 JUnit 用例）

---

## 0. 扫描与过滤（识别之前）

### 0.1 视频扩展名白名单（不区分大小写）

`mkv` `mp4` `m4v` `avi` `mov` `wmv` `flv` `ts` `m2ts` `rmvb` `webm` `mpg` `mpeg` `vob` `3gp`

### 0.2 一律跳过的条目

- 隐藏文件/目录（`.` 开头）
- 系统目录：`@eaDir`、`#recycle`、`$RECYCLE.BIN`、`Thumbs.db` 所在层
- 非视频扩展名（字幕 `.srt .ass .ssa .vtt`、图片、`.nfo`、`.txt`、`.torrent` 等）
- 文件名（去扩展名后）含以下关键词的视为样片/预告，跳过：`sample`、`trailer`、`预告`、`样片`

### 0.3 扫描深度与数量上限（防失控）

- 最大递归深度：**5 层**
- 单连接总文件数上限：**20000 个视频**，超出截断并在 UI 提示
- 单目录视频超过 500 个：不生成剧集条目，直接按文件列表展示

## 1. 目录 → 条目 的组织规则

| 场景 | 判定 | 条目形态 |
|---|---|---|
| 目录内有 ≥2 个视频文件 | 该目录 = 一部剧集 | 剧名取**目录名**，文件排序生成集列表 |
| 目录内只有 1 个视频文件 | 该目录 = 单集影片（电影） | 剧名取目录名；若目录名清洗后为空则取文件名清洗结果 |
| 目录下第一层全是「季目录」（见 1.1） | 该目录 = 多季剧集 | 各季视频合并进同一条目，按季分组展示 |
| 根目录直接散放视频文件 | 每个文件 = 一个单集影片 | 剧名取文件名清洗结果 |

### 1.1 季目录判定（以下任一命中即视为季目录，目录本身不产生条目）

`S01` / `S1` / `Season 1` / `Season1` / `第一季` / `第1季` / `SPECIALS` / `SP` / `OVA` / `番外` / `特别篇`

- `S00` / `SPECIALS` / `SP` / `OVA` / `番外` / `特别篇` → 归入「特别篇」，排在所有正季之后
- 一个目录下同时有季目录和视频文件：视频文件并入第 1 季

---

## 2. 集号识别规则（按优先级，命中即停）

> 所有匹配前先做一次「技术标记剔除」（见第 3 节），再在剩余文本上匹配。

| 优先级 | 规则 | 模式 | 示例 → 结果 |
|---|---|---|---|
| R1 | 西式季集 | `S01E02` / `S1E2` / `s01.e02` | `Show.S02E11.1080p` → 第 2 季第 2 集 |
| R2 | 中文集 | `第12集` / `第12话` / `第12期` / `第12回`，支持中文数字 | `都市之最强律师 第06集` → 第 6 集；`灵剑尊 第十二集` → 第 12 集 |
| R3 | EP 前缀 | `EP12` / `E12` / `ep12`，前后需为边界（非字母） | `少年白马行 EP18` → 第 18 集 |
| R4 | 方括号集号 | `[12]` / `【12】`（内容为 1-3 位纯数字） | `猫町物语 [08]` → 第 8 集 |
| R5 | 末尾数字 | 文件名去扩展、去技术标记后，**结尾**为 1-3 位数字，且前面至少有一个非数字字符 | `山海故人 12` → 第 12 集 |
| R6 | 日期型 | 含 `2024.01.15` / `2024-01-15` 等日期 | **不生成集号**，按日期排序归入「按日期」分组 |
| 兜底 | 无法识别 | — | 按文件名自然排序，依次分配集号 1..N，卡片上仍显示原文件名 |

### 2.1 中文数字支持范围

`一` 到 `九十九`（含 `二十` `三十五` 这类组合）；`零壹` 等繁异体不支持。

### 2.2 集号合法性边界

- 集号超过 **999** → 视为识别失败（大概率是年份或编号串），走兜底
- 同一剧集内集号重复：按第 4 节「多版本」处理
- 同一剧集内出现集号跳号（如 1、2、5）：正常展示，详情页标出缺失集

## 3. 技术标记剔除表（匹配集号/剧名前先从文件名移除）

以下 token 一律移除，且**绝不**作为集号或剧名的一部分：

| 类别 | token（不区分大小写） |
|---|---|
| 分辨率 | `480p` `576p` `720p` `1080p` `1080i` `2160p` `4320p` `4K` `8K` `HD` `FHD` `UHD` |
| 编码 | `x264` `x265` `h264` `h265` `HEVC` `AVC` `AV1` `VP9` `10bit` `8bit` `HDR` `HDR10` `DV` `Dolby` |
| 音频 | `AAC` `AC3` `DTS` `DTS-HD` `TrueHD` `Atmos` `FLAC` `5.1` `7.1` `2.0` |
| 来源 | `BluRay` `BDRip` `WEB-DL` `WEBRip` `HDTV` `DVDRip` `REMUX` |
| 字幕组/发布组 | 外层 `[...]` `【...】` 括号内容（仅当括号内不含纯数字集号时才整个剔除，见 R4） |
| 版本 | `v2` `v3` `v4`（剔除后单独记为「版本号」） |
| 年份 | `19xx` `20xx` 四位数（剔除；不参与集号） |
| 其他 | `修复版` `导演剪辑版` `加长版` `未删减` `国语` `粤语` `中字` `内嵌` `外挂` |

---

## 4. 同集多版本去重

同一剧集内集号相同的多个文件：

1. 版本号高者优先：`v3 > v2 > 无`
2. 同版本比分辨率：`2160p > 1080p > 720p > 其他`
3. 仍相同：文件大者优先
4. 未入选文件不展示、不参与播放；在详情页「文件列表」中可见

---

## 5. 剧名提取规则

| 场景 | 剧名来源 |
|---|---|
| 目录型剧集（含多季） | **目录名**，经第 3 节清洗后取余下文本 |
| 根目录散放单文件 | 文件名去扩展名 → 技术标记剔除 → 去集号部分 → 去首尾分隔符（`.-_ `） |
| 清洗结果为空或过短（<2 字符） | 回退为原始目录名/文件名（不清洗） |

不做联网刮削、不做模糊匹配——目录名是什么就显示什么。

---

## 6. 降级与异常

| 情况 | 行为 |
|---|---|
| 目录内 >50% 文件无法识别集号（且数量 ≥4） | 整个目录按「文件列表」模式展示，不生成集列表 |
| 目录名为空/纯符号 | 用「未命名目录 + 序号」展示，可正常进入 |
| 文件在扫描后被删除/移动 | 详情页进入时校验，失效条目标灰并提示「文件不存在」 |
| NAS 连接失败 | 显示上次扫描缓存结果 + 顶部「连接失败，结果可能不是最新」条 |

## 8. 明确不支持（一期）

- 从 `.nfo` / 文件名刮削海报与简介
- 跨目录合并同一部剧（如 `/剧集A` 与 `/剧集A 续`）
- 音频（音乐）、照片识别
- 用户手动修正识别结果（二期再评估）
